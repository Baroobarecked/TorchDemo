## Quick Start - Human generated

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
docker compose up -d postgres
prefect server start --host 127.0.0.1 # Do this in a separate terminal window
python populate_database.py
python query_data.py "How much money does each player start with in monopoly?"
```

The application will begin by searching through the postgres database for the content that will most closely match the question via vector similarity. If the returned content is void of useful information and the game cannot be identified, it begins the process of looking at an online database to download pdf's for the game being asked about. 

## Configuration - Machine generated, human edited

Copy `.env.example` if starting fresh. The flow reuses
`APP_DATABASE_URL`, `PROVIDER`, and all existing `OLLAMA_*` / `OPENAI_*` settings.
Ollama is the default; OpenAI needs `OPENAI_API_KEY`. Changing the provider/embedding model after an initial run means running `populate_python.py` again.

```text
PREFECT_API_URL=http://localhost:4200/api
RETRIEVAL_MAX_DISTANCE=0.5
```

Any vectors too far away (by default more than 0.5) from the query will not be returned.

The vector extension/tables are initialized automatically. Repeat runs skip existing chunks.
